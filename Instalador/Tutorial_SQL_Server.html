Cómo instalar SQL Server para WardrobeFlow

Esta guía le explica, paso a paso, cómo dejar listo el motor de base de datos que WardrobeFlow necesita. Puede leerla sin conexión a Internet e imprimirla.

1. Qué es SQL Server y por qué lo necesita WardrobeFlow

SQL Server es el motor de base de datos de Microsoft. Es el programa que guarda, de forma ordenada y segura, toda la información de WardrobeFlow: clientes, prendas, pedidos, suscripciones, usuarios, permisos y la bitácora de operaciones.

WardrobeFlow no funciona sin una instancia de SQL Server, porque cada pantalla de la aplicación lee y escribe en la base de datos WardrobeFlowDB. El instalador de WardrobeFlow crea esa base automáticamente; usted solo necesita que exista un SQL Server en el equipo (o en un servidor de la red).

Versión mínima

WardrobeFlow requiere SQL Server 2012 o posterior. Se recomienda SQL Server 2022 Express, que es gratuito.

¿Ya tiene SQL Server instalado?

No necesita esta guía: el instalador de WardrobeFlow detecta las instancias del equipo y le permite elegir la que desea usar.

2. Qué opción le conviene

Recomendada · la más fácil

SQL Server LocalDB

  • Viene incluido en el instalador de WardrobeFlow: no hace falta descargar nada.
  • Se instala con un solo clic, sin preguntas.
  • La base queda disponible solo para el usuario de Windows que instaló.
  • Ideal para un único puesto de trabajo o para una demostración.

Completa

SQL Server 2022 Express

  • Se descarga gratis desde el sitio de Microsoft.
  • Funciona como un servicio de Windows, siempre disponible.
  • La base la pueden usar todos los usuarios de Windows del equipo.
  • Ideal si varias personas usan la misma computadora.

3. Opción fácil: SQL Server LocalDB desde el instalador de WardrobeFlow

El instalador de WardrobeFlow trae incluido SQL Server 2022 Express LocalDB, una versión liviana de SQL Server pensada para un solo usuario.

  1. Ejecute nuevamente el instalador de WardrobeFlow (Instalador_WardrobeFlow_….exe) y acepte el aviso de Control de cuentas de usuario de Windows con Sí.
  2. Avance con Siguiente hasta la página «No se encontró SQL Server en este equipo».
  3. Deje marcada la primera opción: Instalar SQL Server Express LocalDB (recomendado, incluido en este instalador; se instala al confirmar). Ya viene seleccionada.
  4. Haga clic en Siguiente. Se mostrará un aviso que recuerda que la base de LocalDB es solo de su usuario de Windows; ciérrelo con Aceptar.
  5. Continúe con Siguiente y, en la página «Listo para instalar», haga clic en Instalar.
  6. Espere: primero se instala SQL Server LocalDB (aparece una barra de progreso de Windows Installer, sin preguntas) y después WardrobeFlow y su base de datos.
  7. Al terminar, haga clic en Finalizar. WardrobeFlow queda listo para usarse.
Importante: LocalDB es de cada usuario de Windows

La base de datos se crea dentro del perfil del usuario de Windows que ejecutó el instalador. Si otra persona inicia sesión en Windows con otra cuenta y abre WardrobeFlow, no verá los datos. Si varias personas van a usar la aplicación en la misma computadora con cuentas distintas, elija la opción completa.

4. Opción completa: SQL Server 2022 Express

Necesitará una conexión a Internet (se descargan unos 250 MB) y una cuenta de Windows con permisos de administrador. El proceso demora entre 10 y 20 minutos.

4.1. Descargar SQL Server 2022 Express

  1. Abra el navegador e ingrese en la página oficial de descargas de Microsoft:
    https://www.microsoft.com/es-es/sql-server/sql-server-downloads
  2. Busque la sección Express (edición gratuita) y haga clic en Descargar ahora.
  3. Se descargará un archivo pequeño, con un nombre similar a SQL2022-SSEI-Expr.exe. Es el asistente que descarga e instala el resto.
Descargue solo desde el sitio de Microsoft

No use instaladores de SQL Server obtenidos de otros sitios. El sitio de Microsoft puede cambiar de diseño con el tiempo; si no encuentra el botón, busque «SQL Server 2022 Express» dentro de la misma página.

4.2. Ejecutar la instalación

  1. Abra el archivo descargado (haga doble clic en él desde la carpeta Descargas). Cuando Windows lo pregunte, permita que realice cambios con Sí.
  2. En la primera pantalla, elija el tipo de instalación Básica. Es la más simple y deja todo configurado como WardrobeFlow lo espera.
  3. Lea los términos de licencia de Microsoft y haga clic en Aceptar.
  4. Deje la carpeta de instalación propuesta y haga clic en Instalar.
  5. Espere a que termine la descarga y la instalación. Puede tardar varios minutos; no cierre la ventana ni apague el equipo.
  6. Al finalizar, se mostrará la pantalla «La instalación se completó correctamente» con un resumen. Anote estos datos:
    • Nombre de instancia: SQLEXPRESS
    • Conexión: localhost\SQLEXPRESS (equivale a .\SQLEXPRESS)
  7. Haga clic en Cerrar. No hace falta instalar SSMS (SQL Server Management Studio) para usar WardrobeFlow.
Sobre los permisos

La instalación «Básica» agrega como administrador de SQL Server (rol sysadmin) a la cuenta de Windows con la que usted instaló. Por eso conviene instalar WardrobeFlow con esa misma cuenta.

4.3. Verificar el servicio

Antes de volver al instalador de WardrobeFlow, confirme que el servicio de SQL Server está en ejecución, tal como se explica en la sección 5. Normalmente ya lo está: la instalación lo deja iniciado y con inicio automático.

4.4. Volver a ejecutar el instalador de WardrobeFlow

  1. Ejecute nuevamente el instalador de WardrobeFlow.
  2. Ahora el instalador detecta SQL Server y muestra la página «Se encontró SQL Server en este equipo».
  3. Elija la instancia .\SQLEXPRESS (SQL Server 2022) y haga clic en Siguiente.
  4. El instalador verifica el servicio y los permisos antes de copiar archivos. Continúe con Siguiente y Instalar, y al terminar haga clic en Finalizar.
Si el instalador no muestra la instancia

Elija Otra instancia o servidor (ingresar manualmente) (o, en la página «No se encontró SQL Server», Ya tengo SQL Server instalado … — ingresar manualmente) y escriba .\SQLEXPRESS.

5. Cómo verificar que el servicio está en ejecución

  1. Presione las teclas Windows + R. Se abre la ventana «Ejecutar».
  2. Escriba services.msc y haga clic en Aceptar. Se abre la consola «Servicios».
  3. Busque en la lista el servicio SQL Server (SQLEXPRESS) (la lista está en orden alfabético).
  4. Compruebe las columnas Estado y Tipo de inicio. Deben mostrar lo siguiente:
NombreEstadoTipo de inicio
SQL Server (SQLEXPRESS)En ejecuciónAutomático

Esquema de los valores esperados (no es una captura de pantalla).

Si el estado no es «En ejecución» o el tipo de inicio no es «Automático», siga los pasos de «El servicio está detenido o deshabilitado».

LocalDB no aparece en «Servicios»

SQL Server LocalDB no funciona como servicio de Windows: se inicia solo cuando WardrobeFlow lo necesita. Es normal que no figure en la lista.

6. Solución de problemas frecuentes

El servicio está detenido o deshabilitado
  1. Abra la consola «Servicios» (Windows + R, services.msc, Aceptar).
  2. Haga clic derecho sobre SQL Server (SQLEXPRESS) y elija Propiedades.
  3. En Tipo de inicio, seleccione Automático y haga clic en Aplicar.
  4. Haga clic en Iniciar y espere a que el estado cambie a «En ejecución». Luego, haga clic en Aceptar.
  5. Vuelva a ejecutar el instalador de WardrobeFlow.

El instalador de WardrobeFlow intenta iniciar el servicio por su cuenta; si no lo logra, normalmente se debe a la falta de permisos (vea el punto siguiente). Si el servicio se detiene apenas se inicia, revise el Visor de eventos de Windows (eventvwr.msc → Registros de Windows → Aplicación) y busque errores de origen «MSSQL$SQLEXPRESS».

No tiene permisos suficientes (se necesita un administrador)
  • Permisos de Windows: tanto el instalador de SQL Server como el de WardrobeFlow necesitan permisos de administrador. Si Windows le pide una contraseña de administrador y usted no la tiene, solicite ayuda al responsable de sistemas.
  • Permisos dentro de SQL Server: la cuenta de Windows que instala WardrobeFlow debe ser administradora de la instancia (sysadmin) o, al menos, poder crear bases de datos (rol dbcreator). El instalador lo verifica antes de copiar archivos y le avisa si no se cumple.
  • Si SQL Server lo instaló otra persona, pídale que le asigne el rol dbcreator, o ejecute el instalador de WardrobeFlow con la misma cuenta que instaló SQL Server.
  • Como alternativa, elija la opción Instalar SQL Server Express LocalDB en el instalador de WardrobeFlow: LocalDB se instala para su usuario y no necesita permisos sobre el SQL Server existente.
Tiene una versión antigua de SQL Server

WardrobeFlow requiere SQL Server 2012 o posterior. El instalador de WardrobeFlow muestra la versión de cada instancia detectada, por ejemplo .\SQLEXPRESS (SQL Server 2008).

  • Si su instancia es anterior a 2012 (SQL Server 2005, 2008 o 2008 R2), instale SQL Server 2022 Express siguiendo la opción completa. Puede convivir con la versión anterior: si ya existe una instancia llamada SQLEXPRESS, el asistente de Microsoft creará otra con un nombre distinto (por ejemplo, SQLEXPRESS01). Elija esa nueva instancia en el instalador de WardrobeFlow.
  • También puede usar la opción fácil (LocalDB), que instala SQL Server 2022.
Desea conectarse a un SQL Server de otro equipo (servidor remoto)

Al instalar WardrobeFlow, elija ingresar manualmente y escriba el nombre del servidor, por ejemplo SERVIDOR\SQLEXPRESS o SERVIDOR (instancia predeterminada). En el servidor, el administrador debe comprobar lo siguiente:

  1. TCP/IP habilitado: en el Administrador de configuración de SQL Server (SQL Server Configuration Manager), abra «Configuración de red de SQL Server» → «Protocolos de SQLEXPRESS», haga clic derecho en TCP/IP y elija Habilitar. Después, reinicie el servicio de SQL Server. SQL Server Express trae TCP/IP deshabilitado de forma predeterminada.
  2. Puerto y firewall: la instancia predeterminada usa el puerto TCP 1433. Permita ese puerto en el Firewall de Windows del servidor (Firewall de Windows Defender → Configuración avanzada → Reglas de entrada → Nueva regla → Puerto → TCP 1433). Si usa una instancia con nombre, asígnele un puerto fijo en las propiedades de TCP/IP (pestaña «Direcciones IP», sección «IPAll») y permita ese puerto.
  3. SQL Server Browser: para conectarse a una instancia con nombre (por ejemplo, SERVIDOR\SQLEXPRESS) sin indicar el puerto, el servicio SQL Server Browser debe estar en ejecución en el servidor y el puerto UDP 1434 debe estar permitido en el firewall.
  4. Acceso de su usuario: WardrobeFlow se conecta con la autenticación de Windows (su usuario de Windows, sin contraseña adicional). Su cuenta debe tener un inicio de sesión en ese SQL Server con permisos para crear la base (dbcreator o sysadmin). Normalmente esto requiere que ambos equipos pertenezcan al mismo dominio.

El instalador de WardrobeFlow prueba la conexión y los permisos antes de copiar archivos, y le avisa si algo de lo anterior falla.

Otra cuenta de Windows no ve los datos (LocalDB)

SQL Server LocalDB pertenece al usuario de Windows que lo instaló: su base de datos se guarda en el perfil de ese usuario. Si otra persona inicia sesión en Windows con otra cuenta, verá un LocalDB propio y vacío. Para compartir la base entre varias cuentas de Windows, instale SQL Server 2022 Express y vuelva a ejecutar el instalador de WardrobeFlow eligiendo .\SQLEXPRESS.

Falló la instalación de SQL Server LocalDB
  • Revise el registro Documentos\WardrobeFlow_LocalDB_install.log (vea la sección 7).
  • Compruebe que tiene permisos de administrador, que hay espacio libre en el disco y que no hay otra instalación de Windows en curso (por ejemplo, Windows Update). Reinicie el equipo y vuelva a intentarlo.
  • Si el problema continúa, instale SQL Server 2022 Express manualmente.

7. Dónde están los registros (logs) del instalador

Si algo falla, el instalador de WardrobeFlow deja un registro con el detalle técnico. «Documentos» es la carpeta Documentos del usuario de Windows que ejecutó el instalador como administrador.

ArchivoCuándo se genera
Documentos\WardrobeFlow_LocalDB_install.logAl instalar SQL Server LocalDB desde el instalador de WardrobeFlow (registro de Windows Installer).
Documentos\WardrobeFlow_instalacion_fallida.logCuando falla la creación de la base en una instalación nueva y el instalador deshace todo (rollback automático).
Documentos\WardrobeFlow_actualizacion_fallida.logCuando falla la actualización de una versión anterior (la instalación existente se conserva).
Documentos\WardrobeFlow_desinstalacion.logCuando, al desinstalar, no se puede borrar la base de datos.
C:\Program Files\WardrobeFlow\install.log
(con LocalDB: C:\Program Files\WardrobeFlow\Logs\install.log)		Registro de la creación de la base cuando la instalación terminó bien.
%TEMP%\is-XXXXX.tmp\preflight.logVerificaciones previas (conexión, servicio y permisos) durante el asistente. Es temporal: se borra al cerrar el instalador, pero su contenido se muestra en los mensajes de error.
Registro completo del asistente

Para obtener un registro detallado de todo el proceso, ejecute el instalador desde una ventana de símbolo del sistema con el parámetro /LOG, por ejemplo: Instalador_WardrobeFlow_….exe /LOG="%USERPROFILE%\Documents\WardrobeFlow_setup.log"
